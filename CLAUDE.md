# league portfolio

This portfolio is being rebuilt so it feels like the League of Legends client. The work runs one task per session.

- The tracker is `docs/BACKLOG.md`. It holds the session rules, a "Next up" section, task cards and progress. Read it first.
- "Continue the backlog" means: do the task under "Next up", following the session rules.
- History and detail are in `docs/CHECKPOINT.md`. Decisions are in `docs/DECISIONS.md` (once task T01 has created it).
- Hard rules:
  - Ship no Riot assets or fonts, except the in-queue music track (public/sounds/inqueue.mp3), which the owner chose on 2026-11-22 to ship under Riot's fan policy with its notice (see docs/DECISIONS.md → Legal).
  - Stop at 80% of the 5-hour usage window.
  - Push or merge only with the owner's OK.
